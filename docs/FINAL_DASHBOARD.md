- 21·22단계 공식 통과를 사용자 전달로 확인했으며 총공세 마무리 작업을 이어갑니다. 공식 통과는 실제 외부 서버·집행 연결 인증과 구분합니다.
- 선택은 관제 대시보드형과 포장 없이 프로젝트 폴더 실행입니다. 실측 카드 네 개·CPU/메모리 추이·최근 기록은 구현했으며 기존 제출 커밋은 그대로 보존했습니다.
- 사용자 화면과 기록으로 학생 「PC 실측 조회」의 두 번 조회, 네 카드·실제 추이·기록 2회 일치를 확인했습니다. 상세 표는 아래에 기록합니다. 제공 「내 PC 확인」과 구분합니다.
- 사용자 요청으로 마무리 커밋·푸시를 준비합니다. 포털 제출은 아직 하지 않았습니다. 추가 UI 변경은 수정할 파일과 이유를 먼저 제시하고 사용자 확인 뒤 수행합니다.

### 추가 개선 한 가지 — 직전 조회 대비 변화 설명

2026-11-04 사용자가 승인한 후 학생 `extension.mjs`, 이 문서, README만 수정했습니다. 제공 CPU·메모리·디스크 수집기는 그대로 재사용하며 새 OS 수집·관리자 권한·외부 API·포장 기능은 추가하지 않았습니다.

- 네 카드마다 측정 시각(KST)을 붙이고 메모리 사용량·디스크 여유/전체 용량을 GiB로 표시합니다. 조회 전·조회 중·실패·취소·오래된 값은 측정 시각 확인 불가와 그 이유를 카드 안에 표시합니다. 같은 시각의 부분 응답에서 개별 항목만 읽지 못했을 때는 응답의 측정 시각과 해당 항목의 권한 부족 등 이유를 표시합니다.
- 「직전 조회 대비 변화」는 기록 배열의 마지막 두 조회만 비교합니다. CPU·메모리는 사용률 차이 %p, 디스크는 여유 공간 차이 GiB입니다. 원인이나 지속 추세를 추정하지 않습니다.
- 한 번만 조회했거나 현재 실측이 없으면 비교 확인 불가입니다. 직전 조회가 실패·취소됐다면 더 오래된 성공을 찾아 건너뛰지 않습니다. 해당 항목이 양쪽 중 하나라도 확인 불가이면 그 항목의 비교를 거절하며 다른 유효 항목은 비교할 수 있습니다.
- 측정 시각이 같거나 역순이면 전체 비교를 거절합니다. 메모리·디스크의 전체 용량이 달라졌다면 해당 항목은 같은 기준인지 확인할 수 없다고 표시합니다.
- 변화량은 원천 수치에서 계산합니다. 반올림 표시가 0이더라도 실제 작은 차이가 있으면 「0.1%p 미만」 또는 「0.01 GiB 미만」의 증가/감소로 구분합니다. 정확히 같을 때만 변화 없음이라고 씁니다.
- 예시 값은 실제 화면에 추가하지 않았습니다. 시험용 합성 값은 저장소 밖 모의 검사에서만 사용합니다.

화면에 예시 값을 넣지 않았습니다. 테스트의 합성 값은 모의 DOM 검사에만 쓰며 실제 앱 카드·그래프·기록에 주입하지 않습니다. 루트의 `demo` 실행이나 예제 사건은 실제 PC 값과 별도입니다.

## 제공 기능과 학생 개선의 경계

### 네트워크·방화벽·Windows 기록과 SDP 분리 · 2026-11-05

사용자가 승인한 `student/extension.mjs`, 이 문서, README만 확장했습니다. 제공 PC 수집기를 재사용하며 추가 API 호출 없이 같은 버튼의 응답에서 아래 항목을 읽습니다. 상단 카드 네 개와 기존 추이·기록·직전 비교는 유지합니다.

| 항목 | 화면 표시 | 의미와 제한 |
| --- | --- | --- |
| 네트워크 | 인터페이스·IPv4 구성 개수, 측정 시각 | 실제 IP·인터페이스 이름을 저장하거나 표시하지 않음. 인터넷 연결·SDP 접근 허용 판정 아님 |
| 방화벽 | Domain·Private·Public 각각 켜짐/꺼짐, 측정 시각 | 읽기만 함. 켜짐을 PC 전체 안전으로 판단하지 않음 |
| Windows 기록 | System·Application 경고·오류 건수, 조회 시작·측정 시각, 최대 5,000건과 일부 집계 여부 | 최근 24시간의 제공 집계. 본문·사용자·이벤트별 개인정보는 읽어 표시하지 않음. 침해·공격 탐지 결과가 아님 |
| SDP | 별도 제목과 연결 모드 안내 | disconnected는 SDP 미연결. connected·demo·unknown만으로 SDP 인증을 확인할 수 없으므로 연결 여부 확인 불가로 표시 |

- 항목이 unavailable이거나 형식·범위 검증에 실패하면 확인 불가와 사유를 표시합니다. 권한 부족은 「읽기 권한이 없습니다. 관리자 권한으로 바꾸지 않습니다」입니다. 시간 초과·조회 실패·오래됨·조회 전도 0건이나 켜짐으로 바꾸지 않습니다.
- events의 건수는 0 이상의 정수이고 합이 5,000건 이하여야 하며 sampleLimit=5000, truncated 불리언, 유효한 조회 시작 시각이 필요합니다. truncated=true이면 이미 받은 건수와 함께 「일부 집계: 전체 건수가 아닙니다」를 표시합니다.
- 「이 건수는 침해·공격 탐지 결과가 아닙니다」와 「PC 조회 성공은 SDP 연결·업무 앱 접근 허용·보안 인증 성공을 뜻하지 않습니다」를 화면에 표시합니다.
- SDP 표시는 `renderStatus`에 전달된 기존 엔진 모드만 사용합니다. PC API의 응답 성공으로 연결 상태를 바꾸지 않으며, 계약에 없는 SDP 인증 필드를 만들지 않습니다.
- 방화벽·보안 설정 변경, 관리자 권한 상승, 공격·침투 시험, AI 요청·외부 자동 전송은 추가하지 않았습니다. 네트워크·이벤트 원문 객체를 화면·기록에 통째로 저장하지 않습니다.

## 데이터 처리와 실패 표시

- 자동 조회는 없습니다. 렌더링·메뉴 이동은 실측 API를 호출하지 않으며 「PC 실측 조회」를 누를 때만 요청합니다. 별도 자동 조회 기능은 이번에 만들지 않았습니다.
- 동시에 한 요청만 진행합니다. 제공 API는 자체 시간 제한을 사용합니다. 「조회 화면 취소」는 학생 화면에 늦은 응답이 반영되는 것을 막으며 OS 조회가 물리적으로 취소됐다고 보장하지 않습니다. 해당 요청이 정리되기 전에는 새 요청을 보내지 않습니다.
- 출처 local-pc, schema, 원천 측정 시각과 60초 이내 여부를 확인합니다. 각 수치의 범위·단위도 확인합니다. 누락·잘못된 값은 0 또는 정상으로 바꾸지 않습니다.
- 새 요청 중과 실패·취소 뒤에는 이전 실측값을 현재 카드에서 제거합니다. 과거 결과는 「최근 조회 기록」과 추이에만 남습니다. 성공값은 60초 뒤 현재 값 확인 불가로 바뀌며 이 갱신은 API 재요청을 하지 않습니다.
- 메모리 85% 이상, CPU 85% 이상, 디스크 여유 10% 미만, 방화벽 일부 꺼짐은 사용 편의를 위한 주의 표시입니다. CPU는 짧은 표본이며 방화벽이 모두 켜졌다고 PC 전체 안전을 보장하지 않습니다.
- GiB는 1024³ byte 단위입니다. 메모리는 사용 비율, 디스크는 여유 비율입니다. CPU·메모리만 그래프에 표시하며 실패 지점을 실제 0%처럼 그리지 않습니다.
- 기록은 탭 메모리에만 최대 30회 보관합니다. 개인 식별정보·IP·메모 본문·토큰·인증 파일·서버 원문 오류를 저장하지 않습니다. 실제 값과 별도의 예제 데이터 선택 기능은 없습니다.

## 실행·재현 순서

기존 서버가 실행 중이면 새로 켜지 말고 브라우저에서 Ctrl+F5를 누릅니다. 꺼져 있을 때만 아래를 실행합니다.

```powershell
Set-Location "D:\SR\choi-bujang-secret-vault\on-client"
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

다른 PC에서는 실제 기존 `on-client` 폴더 경로를 사용합니다. 위 절대 경로를 코드에 고정한 것은 아닙니다. `http://127.0.0.1:5189/` → 「보호 현황」 → 「학생 상태·알림 표시」의 「이지스 · 내 PC 실측 대시보드」를 확인합니다.

1. 처음에는 「조회 전」, 네 카드 확인 불가, 기록 0회가 정상입니다. 예시 수치가 먼저 채워지면 안 됩니다.
2. 「PC 실측 조회」를 한 번 누릅니다. 조회 중에는 이전 값이 아닌 확인 불가가 보입니다. 완료 뒤 측정 시각·값·실측/주의/확인 불가를 확인합니다.
3. 완료된 뒤 버튼을 다시 눌러 두 번째 조회를 합니다. 실측 가능한 CPU·메모리의 두 점이 그래프에 나오고 기록은 2회가 됩니다. 값이 우연히 같아도 같은 값을 예제로 채운 것이 아닙니다.
   「직전 조회 대비 변화」의 두 측정 시각이 펼친 기록과 같은지 확인합니다. CPU·메모리는 뒤 사용률에서 앞 사용률을 뺀 %p, 디스크는 뒤 여유 공간에서 앞 여유 공간을 뺀 GiB여야 합니다. 첫 조회 때는 비교 확인 불가가 정상입니다.
4. 「시각·결과·수치 기록 펼치기」로 이전 두 결과를 확인합니다. 필요하면 「항목별 실측 근거와 안내」로 카드 설명을 확인합니다.
5. Ctrl+F5를 누르면 기록이 0회로 초기화됩니다. 설정·DB를 삭제하는 동작은 아닙니다.

문법 확인은 저장소 루트에서 다음 명령으로 합니다.

```powershell
npm --prefix "D:\SR\choi-bujang-secret-vault\on-client" run check
```

종료는 이 앱을 켠 PowerShell 창의 Ctrl+C입니다. 모르는 다른 프로세스를 종료하지 않습니다. 기존 실행·데이터 보존 안내는 [학생 실행 설명서](STUDENT_RUNBOOK.md)를 따릅니다.
